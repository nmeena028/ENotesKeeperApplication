# Enotes Keeper Spring Boot Project

A simple **Spring Boot-based note-taking application** to create, view, edit, and manage notes with user authentication.

---

## 🔹 Features

- User registration and login with Spring Security
- Create, edit, delete, and view notes
- RESTful API endpoints for backend functionality
- Responsive UI using Thymeleaf templates
- Database integration with **H2 / MySQL** (configurable)
- Secure password storage using BCrypt

---

## 🔹 Tech Stack

- **Backend:** Java, Spring Boot, Spring Security  
- **Frontend:** Thymeleaf, HTML, CSS  
- **Database:** H2 (default), can switch to MySQL  
- **Build Tool:** Maven  
- **Version Control:** Git, GitHub
